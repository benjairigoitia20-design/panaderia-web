# SISTEMA DE GESTIÓN WEB — PANADERÍA

## 1. OBJETIVO DEL SISTEMA

Desarrollar un sistema web para gestionar de forma centralizada las operaciones de una panadería:

* Productos
* Recetas
* Ingredientes e insumos
* Inventario
* Producción
* Ventas
* Pedidos
* Clientes
* Proveedores
* Compras
* Caja
* Mermas
* Reportes
* Usuarios y permisos

El sistema debe permitir conocer en todo momento qué se tiene, qué se produce, qué se vende, cuánto cuesta producirlo y cuánto dinero genera el negocio.

# 21. REGLAS IMPORTANTES DEL SISTEMA

1. No modificar stock directamente sin registrar un movimiento.

2. Toda venta debe generar su correspondiente movimiento de inventario.

3. Toda producción terminada debe aumentar el stock del producto terminado.

4. La producción debe descontar los ingredientes utilizados.

5. Toda merma debe quedar registrada.

6. Las recetas deben permitir calcular automáticamente el costo de producción.

7. Los precios de productos deben conservar un historial de cambios.

8. Las operaciones importantes deben quedar auditadas.

9. Los usuarios deben tener permisos según su rol.

10. Los registros importantes no deberían eliminarse físicamente; preferir desactivación o cancelación.

11. Las operaciones críticas deben utilizar transacciones de base de datos.

12. El sistema debe mantener trazabilidad entre:
    Venta → Inventario → Producción → Receta → Ingredientes

13. El sistema debe poder responder preguntas como:

* ¿Cuánto vendimos hoy?
* ¿Qué producto se vende más?
* ¿Cuánto cuesta producir un pan?
* ¿Cuánto margen deja cada producto?
* ¿Qué ingredientes están por agotarse?
* ¿Qué tenemos que producir mañana?
* ¿Cuánto desperdiciamos este mes?
* ¿Cuánto dinero hay en caja?
* ¿Qué pedidos tenemos para hoy?
* ¿Cuánto le debemos a cada proveedor?

INVENTARIO

Y que cada módulo comparta información con los demás, evitando cargar la misma información varias veces.
